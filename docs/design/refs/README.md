# Referensi layout

Gambar di folder ini adalah referensi STRUKTUR layout saja (susunan, spasi, kepadatan, hierarki).
Abaikan warna, logo, konten, dan elemen template (upsell paket, keranjang, bendera bahasa, footer).
Warna dan aturan lengkap ada di docs/DESIGN.md.

Gambar disimpan sebagai WebP lossless (piksel sama dengan PNG aslinya, ukuran lebih kecil).

- list-page.webp → halaman daftar: header panel, strip statistik, toolbar, tabel
- form-page.webp → halaman form create/edit
- dashboard.webp → dashboard: strip statistik, lalu grafik ringkasan (2/3) di samping daftar WO
  mendesak (1/3), lalu aktivitas terbaru. Warna, tren mingguan, dan kartu item berwarna di gambar
  tidak dipakai.
